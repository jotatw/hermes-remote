# Decisões de Arquitetura (ADRs)

Registro das decisões estruturais do projeto. Cada ADR documenta **uma**
decisão: contexto, escolha, consequências e alternativas consideradas.

| ADR | Decisão | Status |
|-----|---------|--------|
| [ADR-001](ADR-001.md) | Manter vanilla JS (sem framework) | Aceito |
| [ADR-002](ADR-002.md) | Gateway único no homeserver | Aceito |
| [ADR-003](ADR-003.md) | Cliente único PWA (não separar apps) | Aceito |
| [ADR-004](ADR-004.md) | Chat indisponível quando notebook dorme | Aceito |
| [ADR-005](ADR-005.md) | Push: Telegram como base, Web Push depois | Aceito |

Ciclo: `Proposto → Aceito → Deprecado/Supersedido`. Aceito é imutável;
mudança de rumo = novo ADR que supersede o anterior.

# ADR-004: Chat indisponível quando notebook dorme (aceito)

## Status

Aceito

## Contexto

O Hermes Agent roda no notebook, que nem sempre está ligado. Quando o
notebook dorme ou desliga, o chat fica tecnicamente indisponível. A
alternativa era rodar uma instância leve do Hermes 24/7 no homeserver para
manter o chat sempre ativo.

## Decisão

Aceitar que o **chat fica indisponível quando o notebook está desligado**.
O dashboard e os comandos do homeserver continuam funcionando normalmente.
O gateway retorna um estado claro ("Notebook offline") em vez de erro genérico.

## Consequências

- Arquitetura mais simples: sem duplicar o agente, sem sincronizar estado
  entre duas instâncias, sem consumo extra no homeserver.
- O usuário entende que chat = notebook ligado; status/energia = sempre.
- Quando o notebook dormir, o gateway precisa responder com estado
  "offline" legível, não timeout.

## Alternativas consideradas

- **Hermes leve 24/7 no homeserver**: chat sempre disponível, mas adiciona
  uma instância a manter, consumo de recursos e complexidade de
  fallback/routing entre as duas. Não justificado pelo uso real.

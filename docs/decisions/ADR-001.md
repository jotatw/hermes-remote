# ADR-001: Manter vanilla JS (sem framework)

## Status

Aceito

## Contexto

O v1 nasceu como "chatbot web estilo Claude Code" e foi adaptado por cima
para ser o controle remoto do Hermes. O app tem ~3.6k LOC, mantido por uma
pessoa, com deploy via rsync sem build step. Avaliamos se a arquitetura
atual (ou uma migração para React/Vue/Svelte) seria a base certa para o v2.

O problema do v1 não era a stack: era CSS monolítico, views com `hidden`,
estado vazando para globais e componentes sem re-render. Esses problemas
existem independentemente do framework escolhido.

## Decisão

Manter **vanilla JavaScript**, sem framework e sem build step, no v2.
Corrigir as falhas estruturais do v1 (roteador real, store com Pub/Sub,
CSS por view) em vez de trocar de stack.

## Consequências

- Deploy continua instantâneo (rsync + restart, sem build).
- Correções atacam a causa (estrutura), não o sintoma (patch).
- Sem dependências de runtime; sem bundle para manter atualizado.
- Exige disciplina manual: convenções de código no lugar de garantias do compilador.

## Alternativas consideradas

- **React + TS + Vite**: reescrita total (~3.6k LOC), adiciona build step,
  e não resolve CSS monolítico nem estado vazando — problemas estruturais
  que existem em qualquer stack.
- **Svelte**: compile-time, bundle pequeno, mas introduz build step para
  ganho marginal num app deste tamanho.

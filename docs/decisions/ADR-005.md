# ADR-005: Push — Telegram como base, Web Push depois

## Status

Aceito

## Contexto

O app precisa notificar o celular (alerta de temperatura, containers,
resumo diário) mesmo quando o PWA não está aberto. O ecossistema já usa
Telegram para o Diário de Saúde e Code Review — o canal já existe e é
testado. A alternativa é Web Push nativo do PWA (VAPID).

## Decisão

**Telegram como canal de notificação base** (agora), **Web Push como
evolução futura**. Notificações de evento do homeserver (temperatura,
container, horário) vão para o Telegram existente; Web Push entra depois,
quando o PWA estiver consolidado.

## Consequências

- Reusa infra já existente (bot Telegram, credenciais, fluxo testado).
- Zero dependência nova para o primeiro ciclo de notificações.
- Web Push adicionado depois traz notificação nativa do PWA mesmo com app
  fechado, sem depender do Telegram — ganho real, mas não bloqueia o v2.

## Alternativas consideradas

- **Web Push nativo (VAPID) agora**: notificação nativa de primeira, mas
  exige configuração de chaves VAPID, subscription management e um canal
  novo do zero — custo maior sem necessidade imediata.
